# Claude Code 指示書：プライバシーポリシー・利用規約の作成と gh-pages 公開

## 作業概要

歌帳アプリ（Utacho）のプライバシーポリシーと利用規約をHTMLで作成し、
gh-pagesブランチに配置してGitHub Pagesで公開できる状態にする。

---

## Step 1：ブランチの確認

現在のブランチが `main` であることを確認する。

```bash
git branch --show-current
```

---

## Step 2：HTMLファイルの作成

リポジトリのルートに以下の2ファイルを作成する。
（gh-pagesブランチに移動する前に、mainブランチ上で内容を作っておく）

| デザイン | 清潔感のあるシンプルなレイアウト。アクセントカラーは紫系（#4a3f8f） |

#### セクション構成

**1. 基本方針**
- 個人情報（氏名・メールアドレス・電話番号等）を一切収集しない旨を明記

**2. 収集するデータ**（テーブル形式で整理）

| データの種類 | 保存先 | 外部送信 |
|---|---|---|
| 登録した曲名・アーティスト名 | 端末内（ローカル） | なし |
| カラオケの点数・記録日・機種 | 端末内（ローカル） | なし |
| タブ名・設定値 | 端末内（ローカル） | なし |
| メモ・キー設定 | 端末内（ローカル） | なし |
| 曲名補完のための検索キーワード | 端末内には保存しない | あり ※ |

※ 曲名補完機能（iTunes検索）を利用した場合のみ

**3. 第三者サービスについて**
- サービス名：iTunes Search API（Apple Inc.）
- 送信データ：検索キーワード（曲名・アーティスト名の一部）
- 送信タイミング：曲登録・編集画面で検索機能を使用したときのみ
- Apple のプライバシーポリシーURL：https://www.apple.com/legal/privacy/jp/

**4. データの保存とバックアップ**
- 全データは端末内のみに保存。開発者はアクセス不可
- バックアップ機能でJSONファイルとして書き出し可能
- アンインストール時にデータは削除される

**5. 広告について**
- 広告なし・広告SDKなし

**6. 子どもの利用について**
- 年齢制限なし・個人情報を収集しないため安全

**7. プライバシーポリシーの変更**
- 変更時は本ページに最新版を公開する旨

**8. お問い合わせ**
- GitHub：https://github.com/Rengemaru/Utacho

## Step 3：gh-pages ブランチの作成と配置

以下のコマンドを順番に実行する。

### 3-1. 作成した2ファイルを一時的にリポジトリ外に退避

作業フォルダ（例：`~/utacho-legal-tmp/`）を作り、2ファイルをコピーする。

```bash
mkdir ~/utacho-legal-tmp
cp privacy-policy.html ~/utacho-legal-tmp/
cp terms-of-use.html ~/utacho-legal-tmp/
```

### 3-2. gh-pages ブランチを新規作成（orphan で）

```bash
git checkout --orphan gh-pages
```

> `--orphan` ＝ 親を持たない完全に空のブランチを作るオプション。main のコードが混入しない。

### 3-3. すべてのファイルをインデックスから削除

```bash
git rm -rf .
```

> mainブランチのコードには影響しない。gh-pagesブランチ上での操作。

### 3-4. 退避しておいた2ファイルをルートに配置

```bash
cp ~/utacho-legal-tmp/privacy-policy.html .
cp ~/utacho-legal-tmp/terms-of-use.html .
```

### 3-5. コミット

```bash
git add privacy-policy.html terms-of-use.html
git commit -m "docs: プライバシーポリシー・利用規約を追加"
```

### 3-6. main ブランチに戻る

```bash
git checkout main
```

## Step 4：完了後にユーザーへ伝えること

### プッシュコマンド（ユーザーが確認後に実行する）

```bash
git push origin gh-pages
```

> **注意：プッシュは実行しないこと。コマンドを提示するだけにする。**
> プッシュ後は即座に外部公開されるため、ユーザーが内容を確認してから実行する。

### GitHub Pages の設定手順

1. GitHubのリポジトリページを開く
2. `Settings` → `Pages` を開く
3. `Source` を `Deploy from a branch` に設定
4. `Branch` を `gh-pages` / フォルダを `/ (root)` に設定
5. `Save` をクリック

### 公開後のURL（予定）

```
https://Rengemaru.github.io/Utacho/privacy-policy.html
https://Rengemaru.github.io/Utacho/terms-of-use.html
```

## 注意事項

- `git push` は実行しない（ユーザーが判断して実行する）
- `main` ブランチのコードには一切触れない
- 既存の `docs/` フォルダの内容は変更・削除しない
- 退避用の一時フォルダ（`~/utacho-legal-tmp/`）は作業完了後に削除してよい
