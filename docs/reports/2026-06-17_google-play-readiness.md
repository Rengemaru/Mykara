## アプリ概要

| 項目 | 内容 |
|---|---|
| アプリ名 | 歌帳（うたちょう） |
| 概要 | カラオケの持ち歌・点数を管理するモバイルアプリ |
| パッケージ名 | `com.rengemaru.utacho` |
| 現在のターゲット | Google Play（Android）で先行公開 |
| 将来のターゲット | App Store（iOS） |
| 技術スタック | React Native + Expo (SDK 54) / expo-sqlite / TypeScript |

---

## アプリの機能（実装済み・動作確認済み）

- 曲の登録・編集・削除（タイトル・アーティスト・キー音域・メモ）
- タブ（カテゴリ）による曲の分類（多対多・自由命名）
- 点数の記録（テンキーUI）・履歴管理・グラフ表示
- DAM / JOYSOUND の機種別点数を2系列で管理
- iTunes Search API による曲名・アーティスト名の補完（アートワーク取得）
- バックアップ（JSON エクスポート・インポート）
- 初回オンボーディング（機種選択）
